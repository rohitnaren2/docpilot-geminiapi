About DocPilot AI

DocPilot AI is an AI-powered document question-answering assistant that allows users to upload documents and ask questions about their content. It uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from the uploaded documents and generate contextual answers using the Gemini language model.

How it works

  • A PDF document is uploaded and its text is extracted.
  • The text is split into small, overlapping chunks.
  • Every chunk is converted into a document embedding and stored for retrieval.
  • A question is matched against the stored chunks through vector search to retrieve the most relevant passages.
  • Gemini generates an answer grounded only in the retrieved context.

Technologies

  • Retrieval-Augmented Generation (RAG) — grounds every answer in the uploaded document.
  • Gemini API — generates the answers in the cloud.
  • gemini-3.5-flash-lite — the language model that writes the answers.
  • Document embeddings — numeric vectors for every chunk.
  • Vector search — MongoDB Atlas Vector Search for retrieval.
  • FastAPI — the backend API serving this application.
